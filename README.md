# Esercizio 02 – Calcolatore IVA in C++

## Descrizione

Semplice applicazione console sviluppata in C++ che permette di calcolare l'importo dell'IVA applicata a un prodotto e il relativo prezzo totale.

L'utente inserisce il prezzo iniziale del prodotto e il programma calcola automaticamente l'importo dell'IVA e il prezzo finale.

## Obiettivi didattici

L'esercizio è stato realizzato per consolidare le conoscenze relative a:

- Dichiarazione e utilizzo delle variabili.
- Dichiarazione e utilizzo delle costanti (`const`).
- Tipi di dati numerici (`int`, `double`).
- Input e output tramite `std::cin` e `std::cout`.
- Operazioni aritmetiche.
- Utilizzo di formule matematiche in C++.

## Funzionalità

- Inserimento del prezzo iniziale del prodotto.
- Calcolo dell'importo dell'IVA.
- Calcolo del prezzo totale IVA inclusa.
- Visualizzazione dei risultati tramite console.

## Esempio di esecuzione

```text
Inserisci il prezzo del prodotto: 100

--- RIEPILOGO ---
Prezzo iniziale: 100
IVA (22%): 22
Prezzo totale: 122
```
